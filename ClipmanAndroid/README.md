# Clipman Android

Clipman Android is the Android client for Clipman Server. It lets Android users browse, search, copy, add, edit, pin, delete, and open links from a shared Clipman text history while the app is open.

For user setup and testing instructions, read `Manual.html`.

Server setup can import the private `.clpconf` connection file generated by Clipman Server, avoiding manual entry of a long address and token. Open the file from Android's file browser to send it to Clipman, or use **Import server connection file** in Clipman Settings. Settings can also export the currently configured address and token to a new `.clpconf`; that credential file must be stored and shared securely. Server mode requires a nonblank, preferably unique history password and does not connect merely because the file was imported.

Settings can optionally require biometric or device authentication whenever Clipman returns to the foreground. This is off by default. For private-CA HTTPS servers, install the server's public authority as an Android CA certificate; Clipman opts into user-installed authorities for its server connection.

Clipman can check the official GitHub release for updates automatically while it is open, at most once per day, or on demand from Settings. It verifies the downloaded package before Android asks the user to approve installation.

Settings can optionally preserve copied HTML formatting and add a separate Rich Text history section. Android copies HTML and the plain-text fallback together, preserves synchronized RTF fields, and uses plain text for RTF-only entries because Android's standard text clipboard does not publish RTF.

Server mode displays the encrypted local cache before contacting the server. Foreground refresh then uses a fixed five-second revision check, downloads history only when it changed, pauses while Settings is open or the app is in the background, and backs off connection failures. Settings also includes an optional Tip Jar link; tips do not unlock features.
